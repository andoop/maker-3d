# game124 - 我的空岛 · 模型创作与市场

game124 现在由两层编辑体验组成：玩家进入游戏首先来到可建设的 3D 空岛，把完整模型放到地图上；进入“模型工作台”后，才编辑模型内部的方块、形状与材质。原 `game121/tools/island-3d-workbench` 工作台能力完整保留，并升级为统一模型资产系统。

## 空岛主场景

- 启动直接进入低饱和手绘风三岛群：中央原野、西风林岛和晨光山岛三角排布，风丘草盖、暖陶土层与雨岩芯逐级外露；三条同材质浮桥由草、土、岩小块拼成，局部桥块已坠落但通行带连续。下方不渲染海面，只由雾蓝天空隐约暗示海色。
- 从“内置 / 我的 / 市场 / 收藏”模型库选择模型，以半透明整体预览放到岛上。
- 放置点来自真实地面射线，按模型底部中心落地；越界或与其他模型重叠时显示红色并禁止放置。
- 放置完成后不自动选中，重新点击模型后才进入整体操作。
- 完整模型支持场景内直接选择，并通过不受模型遮挡的移动/旋转/缩放 gizmo 操作；同时保留高度微调、复制、删除、撤销和重做。
- 三岛地基共有 2198 个逐级收束的小型倒角单元，并增加 270 个桥体单元与 27 块岛底悬石；远景重做为 21 座分布在 58–225 米、-4–42 米高度的空岛，按近景、中景、远景和天际四档逐步缩小、降饱和并融入雾蓝天空。每座远岛都有草盖、土层、逐级收束岩体和尖根，近中景岛还用小树提供尺度参照，不再是同距离的一圈简单剪影。
- 云景由原来的近远两层扩展成 332 个云团、五个独立深度层：岛底根雾、低空横向云带、中层团云、高空薄云和天际云墙，高低远近都有明显视差；天空穹顶扩大到 320 米以容纳完整远景。所有云层和远岛仍按材质合并，每个批次都低于手机 16 位顶点上限。岛基、云、天空渐变、半球光、日光和补光继续读取同一份“云岬手绘”主题色；新空岛只预置 168 节点的琥珀温室书屋，另外两岛留作玩家建设。树叶、布料、柔光和装饰圆环不参与第一人称碰撞与投影，小体积细节也不投射实时阴影。
- 初始镜头展示完整三岛群；点击任意岛面会把环绕中心切换到该岛，点击三岛外空白区域返回全景。环绕和缩放不会随意把目标拖出画面。
- “我的空岛”提供独立项目列表，可新建、打开、复制、改名和删除；每座空岛分别保存模型、整体变换与摄像机位置。
- 每座自己的空岛都可独立发布或下架；“探索”会聚合玩家公开空岛，支持环绕观察和第一人称只读漫游，离开后完整恢复自己的空岛。玩家自制模型会以经过尺寸校验、去脚本的声明式快照随空岛发布，离线时仍有示范空岛可参观。
- 第一人称预览使用与缩放建筑匹配的超小型角色碰撞体，进入漫游时会在三座岛上依次搜索有多个可移动方向的安全空地；电脑支持 `WASD`、Shift、Space 和鼠标观察，手机在左半屏按下处即时出现动态移动摇杆，右半屏直接拖动观察，不再显示固定的右侧触摸板。角色可以沿三条断裂风格浮桥在岛间移动，也可穿过真实门洞进入室内。
- 水块在第一人称中作为可穿行流体，不再作为人物墙体碰撞；建筑门扇与洞口维持可通行结构。
- 第一人称碰撞使用每种形状的真实占用比例以及 `rx/ry/rz` 旋转后边界；玻璃仍是实体围护，叶团、布料、晶体和装饰环只负责视觉。悬桥、树屋螺旋梯、观星塔贯通梯井及邮递艇登船梯均按角色步高逐段审计。
- 旧的单空岛存档会自动迁移为空岛列表；手机与电脑共用同一份云端工作区。
- 手机端避开右上角小游戏系统胶囊和左侧圆角安全区；模型库与整模型操作使用左侧半屏透明面板，常用操作保持外露。
- 空岛顶栏、模型库、空岛管理、整模型操作、状态提示和漫游 HUD 统一为 Q 版绘本界面：奶油纸张底、天空蓝主操作、太阳黄强调和圆润粗描边；桌面面板以留白浮卡分区，手机弹层点击外部即可收起。

## 模型工作台

- 内置库包含 68 件“云岬手绘工坊”组合模型，覆盖树木、植被、可进入建筑、飞行器、围栏、街景、组合构件、遗迹和山体九类；旧 `builtin:wonder:*` 存档会迁移到最接近的新模型。
- 推荐放置比例不再简单按最长边缩放：以空岛 1.20 米第一人称角色为共同尺度，分别约束门洞、建筑层高、桌床柜体、桥面、道路、水岸、树木和山体的落地尺寸。
- 24 色“云岬手绘”色板、12 种基础尺寸和 18 种语义材质共用同一份美术主题数据：暖雾灰泥、蜂蜜木、风丘草、苔石、雨岩、雾蓝玻璃和锤纹黄铜都采用低频手绘笔触与柔和磨损，不再混用像素草、强饱和晶体和写实水。手机与电脑共享稳定的手绘水材质，避免移动端折射闪烁。
- 七座山体使用各自独立的沙盒高度场：草甸缓丘、苔岩双岭、风蚀针峰、暮雪双脊山、可攀断崖与瀑布溪谷都拥有不对称轮廓和明确地层；雪山由宽山脚、苔线、裸岩带与破碎雪线组成，不再是径向尖锥。“世界树岩塔”则以 45 根纵向节理岩棱、平缓岩冠和 12 条根状基岩形成巨型地标。
- 全部含门的内置模型都使用完全打开的推拉门：建筑与古堡先生成真实空心门洞，再把门扇完整停靠到相邻墙面；花园门和荒城门也滑到门柱或城墙外。每扇门只保留必要的上轨和嵌入拉手，不设置门槛、下导向、滑轮装饰或额外门套，门口始终畅通且不参与碰撞。
- 点击岛上模型的“定制”会创建该实例的独立副本，不会意外修改岛上其他同款模型。
- 从“我的模型”库进入编辑时，修改的是模型源资产。
- 支持圆角方块、球体、圆柱、圆锥、三棱柱、四棱锥、四面体和圆环。
- 基础积木升级为绘本砖、半格砖、精细砖、微型零件、草地薄板、冒险台阶、彩绘收边、木梁、门窗墙片、矮墙、圆润立柱和地形单元。
- 支持暖雾灰泥、磨旧彩木、蜂蜜原木、手绘风丘草、团簇叶片、潮润苔石、暖陶土层、圆润雨岩、日晒古石、燕麦细沙、雾蓝溪水、雾蓝手作玻璃、薄荷晶石、窑烧陶器、亚麻软布、锤纹黄铜、灯芯柔光和壁炉余烬。
- 保留精确 gizmo 拾取、移动/旋转/缩放、包围盒、吸附线、吸管取色、对象图层和 JSON 导入导出。
- “模型库”中可以直接插入内置模型、自己的模型以及允许二次创作的市场模型。
- 模型库保留逐项“保留”、全部保留/清空和复制验收清单，方便继续筛选内置与市场作品。
- 点击工作台“保存”会保存草稿、主动返回空岛，并立即重建对应实例；返回后重新计算模型边界、占地和性能等级，同时恢复之前的实例选择。
- 工作台顶栏、模式工具、属性、新组件、图层、模型库、颜色材质控件和移动端编辑册采用同一套 Q 版视觉令牌；桌面右栏扩大并使用 12px 内容内边距，形状与材质改为两列，颜色改为五列，模型操作改为上下两层卡片；手机编辑册也使用独立 12px 内容边距。常用操作留在顶栏与底栏，详细内容按标签分页。

## 模型市场

- 模型资产拥有永久 `assetId`、不可变发布 `versionId`、作者、说明、分类、许可、性能等级、依赖和署名信息。
- 支持发布、更新版本、收藏、放入空岛、基于作品再创作以及在模型工作台中插入。
- 自己的作品支持下架和重新发布；市场只展示每个模型的最新公开版本，岛上已使用的旧版本不受影响。
- 市场通过 Maker 玩家云变量发布个人模型档案，并用市场活跃度排行榜聚合其他玩家的作品。
- 发布或下架遇到断网会保留待同步状态，下次恢复工作区后自动重试，不会只改本机界面。
- 无网络时仍展示离线精选；玩家实际使用过的市场版本会保存到本地/云端模型库缓存，确保岛屿离线也能恢复。
- 探索页内置 8 座可漫游示范空岛，每座由 270 个经过真实占地校验的模型组成，三座分岛各固定布置 90 个；分别展示生活小镇、森林溪谷、雪岭远征、古堡遗迹、天空港、花园庆典、山岳地貌和暮光夜市。每座都同时设置多组住宅、山地、森林、草地、湖泊与高密度街景设施，并保留贯穿全岛的通行动线。
- 参观状态和第一人称漫游 HUD 都提供“探索更多”，可直接返回探索列表选择下一座空岛。
- 在示例岛之间切换时复用现有天空、岛基、相机与渲染器，只替换模型内容；大型岛屿按每帧组件预算分批载入，“探索更多”也不会先重建自己的空岛。
- 每次发布只公开每个模型的最新不可变版本；已经放入岛上的具体版本不会被作者更新强制替换。
- 市场负载只接受声明式模型数据，脚本、Lua 代码和未知行为字段不会进入运行时。
- 支持模型依赖数据、循环依赖检查、缺失依赖检查、尺寸/组件数量校验和发布负载上限。
- 每位创作者最多同时公开 12 个作品、合计 2400 个组件；超限会在发布前明确提示，不会出现“本地成功但市场不可见”。

## 数据迁移与保存

- `island-project/v2`：保存岛屿及完整模型实例。
- `island-collection/v1`：保存空岛列表、当前空岛与每座独立空岛工程；兼容迁移旧的单空岛存档。
- `model-asset/v1`：保存可复用模型、版本和依赖。
- `model-library/v1`：保存我的模型、收藏、市场缓存和发布历史。
- 第一次运行 v2 时，旧工作台工程和旧自定义模板会自动迁移到“我的模型”，不会覆盖或丢弃。
- 本地与云端各自保存修订号和更新时间；离线编辑产生的新本地版本不会在下次启动时被旧云存档覆盖。
- 空岛操作和模型编辑均自动保存；顶部“保存”可立即触发云端保存。

## 验证

- `tests/model_system_spec.lua` 覆盖模型版本、发布/下架、收藏缓存、依赖循环、许可、旧数据迁移、空岛边界及碰撞。
- `tests/template_quality_spec.lua` 会遍历全部 68 件组合模型，检查九类内容分布、旧命名空间彻底移除、宏观尺度、组件数量、接地、非法尺寸、完全重复块、门后阻挡墙、形状/材质合法性和几何唯一性。
- `tests/model_system_spec.lua` 还会验证旋转后形状碰撞边界、装饰/实体碰撞角色、楼梯与山路动线的逐级高度，并按 1.2 米人物的第一人称运行时规则扫描所有建筑门洞和路线碰撞净空，同时检查 8 座离线探索样例和默认场景预算；`tests/storybook_island_spec.lua` 会阻止岛基颜色漂出共享主题。
- `tests/storage_spec.lua` 覆盖本地离线保存、云端失败降级、云端恢复与新旧存档冲突选择。
- `tests/island_project_store_spec.lua` 覆盖旧存档迁移及空岛新建、切换、复制、改名和删除。
- `tests/island_market_spec.lua` 覆盖空岛发布、跨玩家探索、自制模型安全打包、恶意字段过滤、离线示范与参观资产缓存；`tests/template_quality_spec.lua` 还会逐门校验推拉门完全离开通道，并逐块检查体素山体不使用穿插旋转几何。

## 操作

- 电脑空岛：左键选择或放置；点击岛面聚焦该岛，点击外部空白返回三岛全景；拖动空白环绕当前焦点，滚轮缩放；第一人称中 `WASD` 移动、Shift 加速、Space 跳跃、移动鼠标观察。
- 手机空岛：轻点选择/放置/聚焦岛屿；单指空白环绕当前焦点，双指缩放；第一人称中左半屏按下即在触点生成动态摇杆，右半屏拖动观察，右下角按键跳跃。
- 模型工作台：左键/单指旋转视野，右键或 Shift+左键拖动自由平移，手机双指平移缩放；近距离放大后会启用有上限的灵敏度补偿，拖动不会随镜头半径缩小而变得迟钝。正面、右侧、顶部和等轴按钮只改变观察方向，不会把视野中心拉回原点。`W/E/R` 切换移动、旋转、缩放；`Delete` 删除；`Ctrl/⌘+D` 复制；`Ctrl/⌘+Z` 撤销；`Ctrl/⌘+Shift+Z` 重做。
