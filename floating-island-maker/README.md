# 我的空岛

“我的空岛”是一款可以自由搭建、参观和分享空中世界的 3D 创作游戏。

玩家进入游戏后会来到漂浮在云海上的岛屿。你可以把房屋、树木、山体、道路、围栏、灯具和飞行器等模型放到岛上，慢慢把一片空地建设成自己的小镇、森林、遗迹或幻想世界。

它不只是一个摆放模型的游戏，也带有一套完整的模型工作台。如果模型库里的内容不够用，可以进入工作台，从基础形状开始拼装自己的模型，再把做好的模型放回空岛使用。

## 可以做什么

- **建设空岛**：选择不同地形，在岛上摆放、移动、旋转和缩放完整模型。
- **制作模型**：使用方块、球体、圆柱、圆锥、三角体和圆环等基础形状自由拼装。
- **调整外观**：给组件更换颜色和材质，制作木头、石头、草地、玻璃、水面等效果。
- **保存多个世界**：新建、复制、改名和管理自己的空岛，每座岛分别保存。
- **第一人称漫游**：像沙盒游戏一样在岛上行走、跳跃和飞行，也可以进入建筑内部。
- **探索其他作品**：发布自己的空岛，参观其他玩家的世界，收藏、点赞或留言。
- **复用创作成果**：自己制作的模型可以保存到模型库，在不同空岛之间重复使用。

## 两层创作方式

### 1. 空岛建设

这是游戏的主场景。操作对象是一个完整模型，例如一栋房子、一棵树或一座山。

从模型库选择内容后，把它放到合适的位置。已经放下的模型仍然可以整体移动、旋转、缩放、复制或删除。游戏会保存空岛上的模型、地形和视角，下次打开时可以继续建设。

### 2. 模型工作台

这是更细致的编辑空间。操作对象是组成模型的每一个基础组件。

你可以精确移动、旋转和缩放组件，也可以使用吸附线、包围盒、颜色吸管、图层、撤销和重做等工具。模型保存后会回到空岛，并更新已经使用该模型的实例。

简单理解：**空岛建设负责摆放完整作品，模型工作台负责制作作品本身。**

## 模型库

工程内置了一批可以直接使用或继续改造的模型，覆盖以下内容：

- 房屋、商店、城墙和遗迹；
- 树木、花草、灌木和水边植物；
- 山体、岩石、池塘、道路和台阶；
- 围栏、路灯、座椅、花盆和遮阳伞；
- 飞艇、滑翔器、传送门等幻想道具。

模型使用统一的人物尺度设计。门洞、楼层、桌椅、道路和台阶会尽量保持合理大小，让第一人称角色能够正常进入和行走。

模型数据采用声明式结构，只描述形状、位置、尺寸、颜色和材质，不会把任意脚本作为模型内容执行。浏览器版 Three.js 工作台也使用相同的 JSON v3 格式，可以互相导入和导出。

## 空岛世界

空岛并不是一张固定平面。项目包含多种地形，可以有大小不同、高低错落的岛屿、破碎但可通行的连接桥、远处空岛以及多层云景。

游戏还支持昼夜变化。白天使用明亮的绘本色调，夜晚会出现星空和建筑灯光。玩家可以让时间自动流逝，也可以手动选择合适的时刻欣赏或截图。

传送门可以连接已经发布的空岛。无论岛主自己漫游，还是其他玩家前来参观，都可以通过有效的传送门继续探索另一个公开世界。

## 操作方式

### 电脑

- 在空岛场景中，点击模型进行选择；拖动空白区域旋转视角，滚轮控制远近。
- 放置模式下点击地面确定位置，也可以先调整模型的方向和大小。
- 第一人称使用 `WASD` 移动、`Shift` 加速、`Space` 跳跃，移动鼠标观察。
- 模型工作台使用 `V / B / X` 切换选择、放置和拆除，`W / E / R` 切换移动、旋转和缩放。
- `Ctrl/⌘ + D` 复制，`Ctrl/⌘ + Z` 撤销，`Ctrl/⌘ + Shift + Z` 重做。

### 手机

- 单指点击用于选择或放置，拖动空白区域旋转视角，双指控制平移和缩放。
- 第一人称在左侧按下时出现移动摇杆，右侧拖动控制视野，并提供跳跃、上升和下降操作。
- 常用模型操作会显示在底部单行工具栏，关闭后恢复主操作栏，尽量减少对游戏画面的遮挡。

## 如何打开工程

这是一个完整的 TapTap Maker 项目。使用 TapTap Maker 打开当前 `floating-island-maker/` 目录，即可继续预览和开发。

项目入口是：

```text
scripts/main.lua
```

如果只想体验浏览器版模型编辑器，可以打开仓库中的 [`threejs-workbench/`](../threejs-workbench/) 项目。

## 主要目录

- `.project/`：Maker 识别工程所需的项目配置与资源清单。
- `assets/`：模型缩略图、界面图片和渲染技术资源。
- `scripts/`：游戏入口、空岛场景、模型工作台、市场、存储和界面代码。
- `tests/`：不依赖完整渲染器的核心逻辑回归测试。
- `asset-tools/`：生成和维护模型缩略图等资源的辅助工具。

## 适合从哪里开始阅读

- `scripts/main.lua`：应用入口、状态切换和输入分发。
- `scripts/IslandWorld.lua`：空岛 3D 场景、相机与模型整体操作。
- `scripts/IslandUI.lua`：空岛主界面、模型库和弹窗。
- `scripts/BuilderWorld.lua`：模型工作台的 3D 编辑逻辑。
- `scripts/BuilderUI.lua`：模型工作台界面。
- `scripts/BuiltinTemplates.lua`：内置模型入口。
- `scripts/IslandTerrainCatalog.lua`：内置空岛地形。
- `scripts/ModelAssetStore.lua`：可复用模型、版本与依赖数据。
- `scripts/IslandMarket.lua`：空岛发布、探索与参观数据。
- `scripts/BuilderStorage.lua`：本地和云端保存。

## 测试

`tests/README.md` 中列出了核心回归测试的运行方式。它们会检查模型数据、地形、拾取、坐标轴操作、昼夜、存储和空岛结构等关键逻辑。

例如：

```bash
lua tests/model_system_spec.lua
lua tests/template_quality_spec.lua
lua tests/island_terrain_spec.lua
```
