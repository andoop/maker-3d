# 我的空岛

这是“我的空岛”的 TapTap Maker 工程源码，包含空岛建设、模型工作台、模型库、探索与第一人称漫游等功能。

使用 TapTap Maker 打开当前目录即可继续开发。

## 主要目录

- `.project/`：Maker 项目配置与资源清单。
- `assets/`：图片、模型缩略图和渲染资源。
- `scripts/`：游戏逻辑、场景、界面、模型与存储代码。
- `tests/`：核心逻辑回归测试。
